# オートリワードサービス（Auto Reward Service）

> **「欲望を先回りした自立型家計簿」**

---

## 概要

**オートリワードサービス**は、AI-DLC ハッカソン「人をダメにする」テーマのもとで構築する、  
ストレス検知×財務状況連動型の自動ご褒美提案サービスです。

仕事や私生活で一定以上の「ストレス」を感じたとき、ユーザーの現在の財務状況を自動分析し、  
**「いま、これを買っていい」** という最適なご褒美をプッシュ通知します。

---

## サービスコンセプト

| 項目 | 内容 |
|------|------|
| キャッチコピー | 欲望を先回りした自立型家計簿 |
| テーマ | 人をダメにする |
| ターゲット | 忙しい社会人・育児中の親・フリーランス（ストレスを抱えながら節約を意識している人） |
| コアバリュー | 「頑張った自分」への承認を自動化し、健全な支出と自己肯定感を両立する |

---

## 主要機能

1. **ストレスセンシング**  
   カレンダー・活動量・テキスト入力などの複数シグナルからストレス度を推定。

2. **財務状況分析**  
   口座残高・月次予算・支出パターンをリアルタイム分析し、「今月の余裕額」を算出。

3. **パーソナライズドリワード提案**  
   ストレス度と余裕額を掛け合わせ、ユーザー嗜好に合ったご褒美（食事・体験・商品等）を提案。

4. **オートリワード実行（将来機能）**  
   承認ワンタップ or 完全自動実行（デリバリー注文・チケット予約など）。

5. **振り返りダッシュボード**  
   ご褒美の履歴・ストレスログ・財務影響をビジュアライズ。
