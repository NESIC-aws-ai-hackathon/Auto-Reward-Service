# Unit 6: Push 通知 — ビジネスルール

## BR-6-01: Push 配信時間帯ルール

| ルール | 内容 |
|--------|------|
| 配信時間帯 | 10:00〜21:00（JST）のみ |
| 配信タイミング | 毎日 1 回、ランダム時刻 |
| ランダム生成タイミング | 毎朝 10:00 に一括生成 |
| ディスパッチ間隔 | 10 分おき |

## BR-6-02: 月間通数制限

| ルール | 値 |
|--------|------|
| フリープラン月間上限 | 200 通 |
| 安全マージン上限 | 190 通（10通バッファ） |
| 上限到達時 | 当月の全 Push を停止 |
| カウントリセット | 毎月 1 日に PROFILE.push_count_this_month = 0 |

## BR-6-03: メッセージ生成ルール

| ルール | 内容 |
|--------|------|
| 必ず具体的話題を含む | 「ねーねー！」だけは禁止 |
| 必ず問いかけで終わる | Yes/No、2択、短い回答で返せる質問 |
| ユーザーデータに接続 | 可能な限り過去の支出・嗜好・予算を参照 |
| 同じテンプレート繰り返し禁止 | 過去 7 日間の PUSH_LOG と照合 |

## BR-6-04: カテゴリ選択ルール

| 条件 | 動作 |
|------|------|
| 記念日 7 日以内 | anniversary_approach を最優先 |
| 嗜好データ < 5 件 | deep_dive_preference の重み = 5 |
| 嗜好データ >= 5 件 | specific_recommendation の重み = 5, deep_dive = 1 |
| 最近 14 日の支出なし | past_reference の重み = 0 |
| PUSH_SETTINGS で特定カテゴリ OFF | そのカテゴリを除外 |

## BR-6-06: 時間帯別トーンルール

| 時間帯 | トーン例 |
|--------|---------|
| 10:00〜12:00 | 「ねね、」「そういえばさ、」「ちょっと聞きたいんだけど、」 |
| 12:00〜14:00 | 「お昼だ！」「ランチ中？」「ごはん食べた？」 |
| 14:00〜17:00 | 「ちょっと聞いてよ〜」「ひまな時でいいんだけど、」「急にごめんね笑」 |
| 17:00〜19:00 | 「おつかれ！」「仕事終わった？」「もう帰り？」 |
| 19:00〜21:00 | 「夜だけどさ、」「寝る前にちょっと！」「今日もおつかれ〜！」 |

## BR-6-07: 月初レポートルール

| ルール | 内容 |
|--------|------|
| 配信日時 | 毎月 1 日 JST 9:00 |
| 繰り越し計算 | finance_engine.calculate_monthly_budget() |
| 含める情報 | 先月予算・支出合計・残額・繰り越し額・今月新予算 |
| 設定 OFF 時 | monthly_report = false ならスキップ |

## BR-6-08: 嗜好抽出ルール

| ルール | 内容 |
|--------|------|
| 抽出タイミング | Push 後の返信時（通常会話処理と並行） |
| 抽出対象 | category / items / sentiment / context |
| items が空 | PREF_MEMORY 更新しない |
| 重複排除 | 既存の likes と照合し新規のみ追加 |
| カテゴリ | food / entertainment / hobby / lifestyle / fashion / place / brand / other |

## BR-6-09: チャットからの設定変更ルール

| ユーザー発言パターン | 変更内容 |
|---|---|
| 「静かにして」「通知オフ」「うるさい」 | all_enabled = false |
| 「また連絡して」「通知オン」「話しかけて」 | all_enabled = true |
| 「おすすめはいらない」 | recommendation = false |
| 「記念日の通知いらない」 | anniversary = false |
