# LIFF 追加機能指示書 v3：オンボーディングフォーム ＆ リワードちゃん機能群

## 概要

Unit 7（LIFF）に以下の機能を追加する：

1. **オンボーディングフォーム** — LIFF フォームで一括登録（その他は動的テーブル追加方式）
2. **「リワードちゃんと話す」ボタン** — リッチメニューから postback → Reply（Push 通数ゼロ）
3. **「おすすめしてもらう」ボタン** — リッチメニューから postback → ヒアリング → 提案（Push 通数ゼロ）
4. **チャットからプロフィール自動更新** — 会話の中で固定費や記念日の変更を自動反映
5. **追加機能群** — リッチメニュー6ボタン構成、Flex Message カード、月次レポート、クイック支出入力、連続記録ご褒美

---

## ★ 重要：Push vs Reply の設計方針

リッチメニューのボタンは **postback アクション** を使用する。
postback イベントには **replyToken** が付くため、**すべて Reply で返せる**。
Push 通数は **ゼロ**。

```
リッチメニューのボタンタップ
  → LINE Platform が postback イベントを Webhook に送信
  → replyToken 付き
  → Lambda が Reply で応答
  → Push 通数: 0 ✅
```

## 3. チャットからプロフィール自動更新

### 3.1 対応パターン

| ユーザーの発言例 | 自動更新内容 |
|---|---|
| 「家賃8万から9万に上がった」 | FIXED_COSTS# の家賃を 90000 に更新 |
| 「Netflix 解約した」 | FIXED_COSTS# から Netflix を削除 |
| 「Disney+ 入った 990円」 | FIXED_COSTS# に Disney+ 990 を追加 |
| 「昇給して手取り32万になった」 | PROFILE# の monthly_income を 320000 に更新 |
| 「彼女の誕生日 8月3日」 | ANNIVERSARY# にパートナー誕生日を追加 |

### 3.2 実装

```
ユーザー: 「Netflix 解約したよ」
  → intent_classifier → PROFILE_UPDATE
  → profile_updater.py → Bedrock で構造化抽出
  → DynamoDB 更新 + ご褒美枠再計算
  → Reply:「Netflix やめたんだ〜了解！🎀
            固定費 990円減ったから、ごほうび枠ちょっと増えるね✨」
```

## 4. 「リワードちゃんと話す」（postback → Reply）

### 4.1 フロー

```
リッチメニュー「🎀 話す」タップ
  → postback: action=start_talk
  → replyToken 付き ✅
  → webhook_handler → talk_starter
  → Reply で話しかけ（Push 通数: 0）
  → ユーザーが返信 → 通常の会話フロー → 嗜好を PREF_MEMORY# に蓄積
```

### 4.2 話しかけパターン

```python
        "{name}まであと{days}日だよ〜🎂\n何か準備する？",
    ],

```

### 4.3 webhook_handler の postback ルーティング

```python
def _route_postback(event):
    data = parse_qs(event["postback"]["data"])
    action = data.get("action", [None])[0]
    user_id = event["source"]["userId"]
    reply_token = event["replyToken"]

    if action == "start_talk":
        reply = talk_starter.generate(user_id)
        line_service.reply_message(reply_token, reply)

    elif action == "start_recommend":
        reply = recommend_flow.start(user_id)
        line_service.reply_message(reply_token, reply)

    elif action == "quick_expense":
        reply = quick_expense.show_options(user_id)
        line_service.reply_message(reply_token, reply)

    elif action == "monthly_summary":
        reply = monthly_report.generate(user_id)
        line_service.reply_message(reply_token, reply)
```

### 6.4 連続記録ごほうび演出（ストリーク）

支出記録を続けるとリワードちゃんが褒めてくれる。

```
3日連続記録:
  リワードちゃん: 「3日連続で記録してくれてる！えらい〜✨」

7日連続記録:
  リワードちゃん: 「1週間連続！！すごくない？🎉
                  ちょっと自分にごほうびしてもいいかもね😏」

30日連続記録:
  リワードちゃん: 「1ヶ月連続記録達成〜〜！！🏆🎊
                  もうプロだね笑 何か欲しいものリストから選んじゃう？🎁」
```

#### DynamoDB

```
PK=USER#xxx  SK=STREAK#
{
  "current_streak": 7,
  "longest_streak": 14,
  "last_record_date": "2026-05-16"
}
```

#### 実装

```python
def _update_streak(user_id: str) -> Optional[str]:
    streak = dynamodb_service.get_streak(user_id)
    today = date.today()

    if streak["last_record_date"] == str(today):
        return None  # 今日は既に記録済み

    if streak["last_record_date"] == str(today - timedelta(days=1)):
        streak["current_streak"] += 1
    else:
        streak["current_streak"] = 1

    streak["longest_streak"] = max(streak["longest_streak"], streak["current_streak"])
    streak["last_record_date"] = str(today)
    dynamodb_service.put_streak(user_id, streak)

    # マイルストーンチェック
    milestones = {3: "3日連続！えらい〜✨", 7: "1週間連続！すごくない？🎉", 30: "1ヶ月達成！もうプロだね🏆"}
    return milestones.get(streak["current_streak"])
```
