# ARS 追加機能指示書：寄り道レーン（Detour Lane）

## 概要

既存の Auto-Reward-Service（ARS）に「寄り道レーン」機能を追加する。

> **「疲れた日の帰り道を、リワードちゃんが実際の寄り道ルートに変える」**
>
> ユーザーが「今日もう無理」「帰り道で甘えたい」と送るだけで、
> 現在地から寄り道できるスポットをリワードちゃんが提案する。
> ARS はただの家計簿ではなく「現実の帰り道に誘惑を差し込むアプリ」になる。

---

## 1. ユーザーストーリー（US-9: 寄り道レーン）

```
疲れて帰る社会人として、
私は「今日もう無理」と LINE で話しかけるだけで、
現在地から寄り道できるスポットをリワードちゃんに提案してほしい。
それによって、自分で店や買うものを考えずに、
自然とお金を使う帰り道に乗れるようにしたい。
```

---

## 2. 全体フロー

```
ユーザー: 「今日もう無理。帰り道で甘えたい」
  ↓
webhook_handler → intent_classifier → TEMPTATION
  ↓
temptation_engine.start()
  ↓
Reply:
  「今日はまっすぐ帰る日じゃないかも🎀
   現在地から、寄り道できるスポットを探すね！
   下のボタンから現在地を教えて✨」
  [🗺️ 寄り道レーンを作る]  ← LIFF URL
  ↓
LIFF画面 → Geolocation API で現在地取得
  ↓
POST /api/temptation/start (lat, lng, message)
  ↓
location_service.search_nearby_reward_places()
  ↓
temptation_engine.build_lanes()
  ↓
LIFF画面に寄り道レーン3件表示
  ↓
ユーザーが「この寄り道で帰る」をタップ
  ↓
POST /api/temptation/accept
  ↓
後日: 「カフェ 680円」→ EXPENSE# に temptation_session_id 紐付け
```

## 5. Location Service

### 5.1 Google Maps Places API（ハッカソン向け）

Amazon Location Service より Google Maps Places API の方がハッカソンでは手軽。

```python
# layer/python/services/location_service.py

import os
import json
import urllib.request
from typing import Optional

GOOGLE_MAPS_API_KEY = os.environ.get("GOOGLE_MAPS_API_KEY", "")
USE_MOCK_LOCATION = os.environ.get("USE_MOCK_LOCATION", "false") == "true"

# lane_type → Google Places の type マッピング
LANE_TYPE_TO_PLACE_TYPES = {
    "CAFE_REBOOT": ["cafe", "bakery"],
    "CONVENIENCE_RECOVERY": ["convenience_store"],
    "SELF_COOKING_ESCAPE": ["restaurant", "meal_delivery"],
    "LOW_COST_RECOVERY": ["convenience_store", "drugstore"],
    "RICHER_ESCAPE": ["restaurant", "shopping_mall"],
}


def search_nearby_reward_places(
    lat: float,
    lng: float,
    lane_type: str,
    radius_m: int = 800,
) -> list[dict]:
    """
    現在地周辺のスポットを検索する。
    Google Maps Places API (Nearby Search) を使用。
    """
    if USE_MOCK_LOCATION:
        return _mock_places_nearby(lat, lng, lane_type)

    place_types = LANE_TYPE_TO_PLACE_TYPES.get(lane_type, ["restaurant"])
    results = []

    for ptype in place_types:
        url = (
            f"https://maps.googleapis.com/maps/api/place/nearbysearch/json"
            f"?location={lat},{lng}"
            f"&radius={radius_m}"
            f"&type={ptype}"
            f"&language=ja"
            f"&key={GOOGLE_MAPS_API_KEY}"
        )
        req = urllib.request.Request(url)
        with urllib.request.urlopen(req) as resp:
            data = json.loads(resp.read())
            for place in data.get("results", [])[:3]:
                loc = place.get("geometry", {}).get("location", {})
                results.append({
                    "name": place.get("name"),
                    "category": ptype,
                    "lat": loc.get("lat"),
                    "lng": loc.get("lng"),
                    "address": place.get("vicinity", ""),
                    "rating": place.get("rating"),
                    "distance_m": _calc_distance(lat, lng, loc.get("lat", 0), loc.get("lng", 0)),
                })

    # 距離順にソート
    results.sort(key=lambda x: x["distance_m"])
    return results[:5]

## 6. temptation_engine.py

```python
# layer/python/services/temptation_engine.py

import uuid
from datetime import datetime
from services import dynamodb_service, finance_engine, location_service, bedrock_service

LANE_DEFINITIONS = {
    "CAFE_REBOOT": {
        "title": "カフェ再起動レーン ☕",
        "estimated_min": 500,
        "estimated_max": 900,
        "ars_category": "情緒安定費",
    },
    "CONVENIENCE_RECOVERY": {
        "title": "コンビニ回復レーン 🏪",
        "estimated_min": 300,
        "estimated_max": 600,
        "ars_category": "回復費",
    },
    "SELF_COOKING_ESCAPE": {
        "title": "自炊放棄レーン 🍜",
        "estimated_min": 800,
        "estimated_max": 1500,
        "ars_category": "グルメ費",
    },
    "LOW_COST_RECOVERY": {
        "title": "低コスト回復レーン 💊",
        "estimated_min": 200,
        "estimated_max": 500,
        "ars_category": "回復費",
    },
    "RICHER_ESCAPE": {
        "title": "ちょっと贅沢レーン ✨",
        "estimated_min": 1500,
        "estimated_max": 3000,
        "ars_category": "グルメ費",
    },
}


def invite_location(user_id: str, message: str) -> dict:
    """
    TEMPTATION intent 検出後、LIFF で現在地取得を促す Reply メッセージを生成。
    """
    liff_url = "https://liff.line.me/2010106872-9t0gN1D6/temptation"

    return {
        "type": "template",
        "altText": "寄り道レーンを作るよ🎀",
        "template": {
            "type": "buttons",
            "text": (
                "今日はまっすぐ帰る日じゃないかも🎀\n"
                "現在地から、寄り道できるスポットを探すね！\n"
                "下のボタンから現在地を教えて✨"
            ),
            "actions": [
                {
                    "type": "uri",
                    "label": "🗺️ 寄り道レーンを作る",
                    "uri": liff_url,
                }
            ],
        },
    }


def build_lanes(user_id: str, lat: float, lng: float, message: str) -> dict:
    """
    現在地・残予算・嗜好から寄り道レーンを3件生成する。
    """
    budget = finance_engine.get_monthly_remaining(user_id)
    prefs = dynamodb_service.get_all_preferences(user_id)

    # 残予算に応じてレーン構成を決定
    if budget < 1000:
        lane_types = ["LOW_COST_RECOVERY", "CONVENIENCE_RECOVERY", "CAFE_REBOOT"]
    elif budget < 5000:
        lane_types = ["CAFE_REBOOT", "CONVENIENCE_RECOVERY", "SELF_COOKING_ESCAPE"]
    else:
        lane_types = ["CAFE_REBOOT", "SELF_COOKING_ESCAPE", "RICHER_ESCAPE"]

    lanes = []
    for lt in lane_types:
        places = location_service.search_nearby_reward_places(lat, lng, lt)
        if not places:
            continue
        definition = LANE_DEFINITIONS[lt]
        lane = {
            "lane_id": f"lane_{lt.lower()}_{uuid.uuid4().hex[:8]}",
            "lane_type": lt,
            "title": definition["title"],
            "estimated_min": definition["estimated_min"],
            "estimated_max": definition["estimated_max"],
            "ars_category": definition["ars_category"],
            "places": places,
            "recommendation_score": _calculate_score(lt, budget, prefs, places),
        }
        lanes.append(lane)

    # スコア順にソート
    lanes.sort(key=lambda x: x["recommendation_score"], reverse=True)

    # Bedrock でリワードちゃんのおすすめ理由を生成
    reason = _generate_reason(user_id, message, lanes, budget)

    # セッション保存
    session_id = str(uuid.uuid4())
    session = {
        "session_id": session_id,
        "status": "proposed",
        "trigger_message": message,
        "created_at": datetime.now().isoformat(),
        "location": {"lat": lat, "lng": lng, "source": "liff_geolocation"},
        "lanes": lanes,
        "recommended_lane_id": lanes[0]["lane_id"] if lanes else None,
        "selected_lane_id": None,
        "completed_expense_id": None,
    }
    dynamodb_service.put_item(
        pk=f"USER#{user_id}",
        sk=f"TEMPTATION_SESSION#{session_id}",
        item=session,
        ttl_days=30,
    )

    return {
        "session_id": session_id,
        "lanes": lanes,
        "recommended_lane_id": lanes[0]["lane_id"] if lanes else None,
        "reason": reason,
    }


def accept_lane(user_id: str, session_id: str, lane_id: str) -> dict:
    """ユーザーがレーンを選択した時の処理。"""
    dynamodb_service.update_temptation_session(
        user_id, session_id,
        status="accepted",
        selected_lane_id=lane_id,
    )
    return {"accepted": True, "lane_id": lane_id}


def _calculate_score(lane_type, budget, prefs, places):
    """レーンのスコアを計算。嗜好・距離・予算を考慮。"""
    base = 50
    if places:
        avg_distance = sum(p["distance_m"] for p in places) / len(places)
        if avg_distance < 200:
            base += 20
        elif avg_distance < 500:
            base += 10
    definition = LANE_DEFINITIONS[lane_type]
    if definition["estimated_max"] <= budget * 0.1:
        base += 15  # 予算の10%以内なら高スコア
    # 嗜好データでブースト
    food_likes = prefs.get("food", {}).get("likes", [])
    if lane_type == "SELF_COOKING_ESCAPE" and any("ラーメン" in l for l in food_likes):
        base += 20
    return min(base, 100)


def _generate_reason(user_id, message, lanes, budget):
    """Bedrock でリワードちゃんのおすすめ理由を生成。"""
    if not lanes:
        return "うーん、近くにいい場所が見つからなかった…ごめんね🎀"

    top_lane = lanes[0]
    prompt = f"""
あなたはリワードちゃん（ギャル系お姉さん）です。
ユーザーが「{message}」と言っています。
残予算は{budget}円です。
おすすめの寄り道レーンは「{top_lane['title']}」で、
近くに{top_lane['places'][0]['name']}があります（徒歩{top_lane['places'][0]['distance_m']//80}分）。
想定金額は{top_lane['estimated_min']}〜{top_lane['estimated_max']}円です。

2〜3行で、このレーンをおすすめする理由をリワードちゃんの口調で書いてください。
    """
    return bedrock_service.invoke_text(prompt)
```

# ARS 追加機能指示書：寄り道レーン（Detour Lane）

## 概要

既存の Auto-Reward-Service（ARS）に「寄り道レーン」機能を追加する。

> **「疲れた日の帰り道を、リワードちゃんが実際の寄り道ルートに変える」**
>
> ユーザーが「今日もう無理」「帰り道で甘えたい」と送るだけで、
> 現在地から寄り道できるスポットをリワードちゃんが提案する。
> ARS はただの家計簿ではなく「現実の帰り道に誘惑を差し込むアプリ」になる。

# layer/python/services/location_service.py

import os
import json
import urllib.request
from typing import Optional

GOOGLE_MAPS_API_KEY = os.environ.get("GOOGLE_MAPS_API_KEY", "")
USE_MOCK_LOCATION = os.environ.get("USE_MOCK_LOCATION", "false") == "true"

# lane_type → Google Places の type マッピング
LANE_TYPE_TO_PLACE_TYPES = {
    "CAFE_REBOOT": ["cafe", "bakery"],
    "CONVENIENCE_RECOVERY": ["convenience_store"],
    "SELF_COOKING_ESCAPE": ["restaurant", "meal_delivery"],
    "LOW_COST_RECOVERY": ["convenience_store", "drugstore"],
    "RICHER_ESCAPE": ["restaurant", "shopping_mall"],
}


def search_nearby_reward_places(
    lat: float,
    lng: float,
    lane_type: str,
    radius_m: int = 800,
) -> list[dict]:
    """
    現在地周辺のスポットを検索する。
    Google Maps Places API (Nearby Search) を使用。
    """
    if USE_MOCK_LOCATION:
        return _mock_places_nearby(lat, lng, lane_type)

    place_types = LANE_TYPE_TO_PLACE_TYPES.get(lane_type, ["restaurant"])
    results = []

    for ptype in place_types:
        url = (
            f"https://maps.googleapis.com/maps/api/place/nearbysearch/json"
            f"?location={lat},{lng}"
            f"&radius={radius_m}"
            f"&type={ptype}"
            f"&language=ja"
            f"&key={GOOGLE_MAPS_API_KEY}"
        )
        req = urllib.request.Request(url)
        with urllib.request.urlopen(req) as resp:
            data = json.loads(resp.read())
            for place in data.get("results", [])[:3]:
                loc = place.get("geometry", {}).get("location", {})
                results.append({
                    "name": place.get("name"),
                    "category": ptype,
                    "lat": loc.get("lat"),
                    "lng": loc.get("lng"),
                    "address": place.get("vicinity", ""),
                    "rating": place.get("rating"),
                    "distance_m": _calc_distance(lat, lng, loc.get("lat", 0), loc.get("lng", 0)),
                })

    # 距離順にソート
    results.sort(key=lambda x: x["distance_m"])
    return results[:5]

## 6. temptation_engine.py

```python
# layer/python/services/temptation_engine.py

import uuid
from datetime import datetime
from services import dynamodb_service, finance_engine, location_service, bedrock_service

LANE_DEFINITIONS = {
    "CAFE_REBOOT": {
        "title": "カフェ再起動レーン ☕",
        "estimated_min": 500,
        "estimated_max": 900,
        "ars_category": "情緒安定費",
    },
    "CONVENIENCE_RECOVERY": {
        "title": "コンビニ回復レーン 🏪",
        "estimated_min": 300,
        "estimated_max": 600,
        "ars_category": "回復費",
    },
    "SELF_COOKING_ESCAPE": {
        "title": "自炊放棄レーン 🍜",
        "estimated_min": 800,
        "estimated_max": 1500,
        "ars_category": "グルメ費",
    },
    "LOW_COST_RECOVERY": {
        "title": "低コスト回復レーン 💊",
        "estimated_min": 200,
        "estimated_max": 500,
        "ars_category": "回復費",
    },
    "RICHER_ESCAPE": {
        "title": "ちょっと贅沢レーン ✨",
        "estimated_min": 1500,
        "estimated_max": 3000,
        "ars_category": "グルメ費",
    },
}


def invite_location(user_id: str, message: str) -> dict:
    """
    TEMPTATION intent 検出後、LIFF で現在地取得を促す Reply メッセージを生成。
    """
    liff_url = "https://liff.line.me/2010106872-9t0gN1D6/temptation"

    return {
        "type": "template",
        "altText": "寄り道レーンを作るよ🎀",
        "template": {
            "type": "buttons",
            "text": (
                "今日はまっすぐ帰る日じゃないかも🎀\n"
                "現在地から、寄り道できるスポットを探すね！\n"
                "下のボタンから現在地を教えて✨"
            ),
            "actions": [
                {
                    "type": "uri",
                    "label": "🗺️ 寄り道レーンを作る",
                    "uri": liff_url,
                }
            ],
        },
    }


def build_lanes(user_id: str, lat: float, lng: float, message: str) -> dict:
    """
    現在地・残予算・嗜好から寄り道レーンを3件生成する。
    """
    budget = finance_engine.get_monthly_remaining(user_id)
    prefs = dynamodb_service.get_all_preferences(user_id)

    # 残予算に応じてレーン構成を決定
    if budget < 1000:
        lane_types = ["LOW_COST_RECOVERY", "CONVENIENCE_RECOVERY", "CAFE_REBOOT"]
    elif budget < 5000:
        lane_types = ["CAFE_REBOOT", "CONVENIENCE_RECOVERY", "SELF_COOKING_ESCAPE"]
    else:
        lane_types = ["CAFE_REBOOT", "SELF_COOKING_ESCAPE", "RICHER_ESCAPE"]

    lanes = []
    for lt in lane_types:
        places = location_service.search_nearby_reward_places(lat, lng, lt)
        if not places:
            continue
        definition = LANE_DEFINITIONS[lt]
        lane = {
            "lane_id": f"lane_{lt.lower()}_{uuid.uuid4().hex[:8]}",
            "lane_type": lt,
            "title": definition["title"],
            "estimated_min": definition["estimated_min"],
            "estimated_max": definition["estimated_max"],
            "ars_category": definition["ars_category"],
            "places": places,
            "recommendation_score": _calculate_score(lt, budget, prefs, places),
        }
        lanes.append(lane)

    # スコア順にソート
    lanes.sort(key=lambda x: x["recommendation_score"], reverse=True)

    # Bedrock でリワードちゃんのおすすめ理由を生成
    reason = _generate_reason(user_id, message, lanes, budget)

    # セッション保存
    session_id = str(uuid.uuid4())
    session = {
        "session_id": session_id,
        "status": "proposed",
        "trigger_message": message,
        "created_at": datetime.now().isoformat(),
        "location": {"lat": lat, "lng": lng, "source": "liff_geolocation"},
        "lanes": lanes,
        "recommended_lane_id": lanes[0]["lane_id"] if lanes else None,
        "selected_lane_id": None,
        "completed_expense_id": None,
    }
    dynamodb_service.put_item(
        pk=f"USER#{user_id}",
        sk=f"TEMPTATION_SESSION#{session_id}",
        item=session,
        ttl_days=30,
    )

    return {
        "session_id": session_id,
        "lanes": lanes,
        "recommended_lane_id": lanes[0]["lane_id"] if lanes else None,
        "reason": reason,
    }


def accept_lane(user_id: str, session_id: str, lane_id: str) -> dict:
    """ユーザーがレーンを選択した時の処理。"""
    dynamodb_service.update_temptation_session(
        user_id, session_id,
        status="accepted",
        selected_lane_id=lane_id,
    )
    return {"accepted": True, "lane_id": lane_id}


def _calculate_score(lane_type, budget, prefs, places):
    """レーンのスコアを計算。嗜好・距離・予算を考慮。"""
    base = 50
    if places:
        avg_distance = sum(p["distance_m"] for p in places) / len(places)
        if avg_distance < 200:
            base += 20
        elif avg_distance < 500:
            base += 10
    definition = LANE_DEFINITIONS[lane_type]
    if definition["estimated_max"] <= budget * 0.1:
        base += 15  # 予算の10%以内なら高スコア
    # 嗜好データでブースト
    food_likes = prefs.get("food", {}).get("likes", [])
    if lane_type == "SELF_COOKING_ESCAPE" and any("ラーメン" in l for l in food_likes):
        base += 20
    return min(base, 100)


def _generate_reason(user_id, message, lanes, budget):
    """Bedrock でリワードちゃんのおすすめ理由を生成。"""
    if not lanes:
        return "うーん、近くにいい場所が見つからなかった…ごめんね🎀"

    top_lane = lanes[0]
    prompt = f"""
あなたはリワードちゃん（ギャル系お姉さん）です。
ユーザーが「{message}」と言っています。
残予算は{budget}円です。
おすすめの寄り道レーンは「{top_lane['title']}」で、
近くに{top_lane['places'][0]['name']}があります（徒歩{top_lane['places'][0]['distance_m']//80}分）。
想定金額は{top_lane['estimated_min']}〜{top_lane['estimated_max']}円です。

2〜3行で、このレーンをおすすめする理由をリワードちゃんの口調で書いてください。
    """
    return bedrock_service.invoke_text(prompt)
```

## 10. 支出記録との連携

### 10.1 フロー

```
ユーザーがレーンを accept
  → status = "accepted"
  → ユーザーが実際にお店に行く
  → LINE で「カフェ 680円」or レシート画像を送る
  → 既存の EXPENSE 記録フロー
  → EXPENSE# に以下を追加:
    {
      "temptation_session_id": "uuid",
      "lane_type": "CAFE_REBOOT",
      "place_name": "駅前カフェ",
      "location_based": true
    }
  → TEMPTATION_SESSION# の status を "completed" に更新
  → completed_expense_id を設定
```

### 10.2 expense_extractor.py の修正

```python
def _check_active_temptation(user_id: str) -> Optional[dict]:
    """accepted 状態の寄り道セッションがあるかチェック。"""
    sessions = dynamodb_service.query(
        pk=f"USER#{user_id}",
        sk_begins_with="TEMPTATION_SESSION#",
    )
    for s in sessions:
        if s.get("status") in ("accepted", "navigating"):
            return s
    return None
```
