## 🚀 セットアップ（最初の1回だけ）

### Step 1: LINE友達追加

ふれまーるちゃんを友達追加してください（QRコードまたはID検索）。

---

### Step 2: ダッシュボードをホーム画面に追加（iPhone）

LIFF画面（ダッシュボード・寄り道レーン）はブラウザアプリとしてホーム画面に追加できます。

#### 手順

**① SafariでLIFF URLを開く**

LINE アプリでふれまーるちゃんとトーク後、以下の URL を **Safariで直接** 開きます。

```
https://liff.line.me/2010106872-9t0gN1D6
```

> ⚠️ LINEアプリ内ブラウザからではなく、**必ずSafari**で開いてください。  
> （LINEアプリ内のリンクを長押し → 「Safariで開く」を選択）

---

**② LINEログイン**

Safariで開くとLINEのログイン画面が表示されます。  
「LINEでログイン」をタップしてください。

---

**③ ホーム画面に追加**

1. Safariの画面下部にある **共有ボタン**（四角から矢印が出ているアイコン）をタップ  
2. 下にスクロールして **「ホーム画面に追加」** をタップ  
3. 名前は「ふれまーるちゃん」のまま **「追加」** をタップ

```
Safari下部のアイコン:
┌──────────────────────┐
│  ＜  https://liff...  ＞  │
└──────────────────────┘
         ⬆️ 共有ボタン（↑アイコン）
```

---

**④ 完了！**

ホーム画面に 🌿 アイコンが追加されます。  
次回からはそのアイコンをタップするだけで起動できます。

## 💬 日常の使い方

### ① 支出をLINEで記録する

LINEのトーク画面に **商品名と金額** を送るだけです。

```
（例）
「スタバでラテ 650円」
「コンビニ 320円」
「本 1200円」
```

ふれまーるちゃんが「記録したよ〜🌿」と返信します。

---

### ② ご褒美を提案してもらう

LINEに **気持ちや状態** を送ります。

```
（例）
「疲れた」
「今日頑張った」
「ちょっと自分にご褒美したい」
```

予算の範囲内で今日のご褒美候補を提案してくれます。

---

### ③ 寄り道レーンを使う（帰り道に寄り道）

1. LINEで「寄り道したい」「どこか寄って帰りたい」と送る
2. ふれまーるちゃんからFlexMessageが届く
3. **「🗺️ 現在地から寄り道スポットを探す」** をタップ
4. LIFF（PWA）が開く
5. **「📍 現在地を使う」** をタップ（または駅名・エリア名で検索）
6. 近くのスポットが3レーンで提案される
7. 気に入ったレーンの **「このレーンに決めた！」** をタップ
8. お店情報がLINEに届く 🎉

帰ってきたら支出もワンタップで記録できます。

---

### ④ ダッシュボードを確認する

ホーム画面のアイコン、またはLINEの「ダッシュボード」メニューから確認できます。

- 📊 今月の支出グラフ
- 🎁 ご褒美予算の残高
- 📅 支出履歴

## ❓ よくある質問

### Q. ホーム画面に追加できない

- **Chromeでは追加できません**。必ず **Safari** を使ってください。
- iOS 16.4 以降が必要です（設定 → 一般 → 情報でiOSバージョンを確認）。

### Q. 開くとログイン画面が毎回出る

- ホーム画面から開く際は初回のみLINEログインが必要です。
- 一度ログインすればトークンがキャッシュされます。

### Q. 位置情報を使えない

- Safariの設定で位置情報を許可してください。  
  設定 → Safari → このWebサイトの設定 → 位置情報 → **許可**
- 位置情報が使えない場合は「エリア名で検索」が使えます（例: 渋谷、新宿三丁目）。

### Q. 支出が記録されない

- LINEのトーク画面で「金額（数字）」が含まれているか確認してください。
- 「昨日1000円使った」など過去の支出も対応しています。
