# ふれまーるちゃん 静的PWAデモ

S3 + CloudFront などにそのまま配置できる静的サイトです。  
GitHub Copilot に本実装を引き継ぐための、**画面構成・見た目・アセット配置・機能導線**が分かる静的モックとして使えます。

---

## 1. この ZIP の役割

この ZIP は、以下を Copilot に渡しやすくするための土台です。

- ふれまーるちゃんの世界観を反映した UI
- 画面ごとの役割が分かる構造
- どのエリアにどの機能を実装するか分かるレイアウト
- ふれまーるちゃんの表情差分・ナマケモノ画像などのアセット一式
- **チャットで感情に応じてアバターを切り替える前提**の画像整理

---

## 2. 配置方法

`furemaru_static_site` 配下のファイルを S3 バケットのルートにアップロードしてください。

- `index.html`
- `styles.css`
- `app.js`
- `manifest.json`
- `sw.js`
- `assets/`

React やビルド環境は不要です。  
HTML / CSS / JavaScript だけで動く**静的サイト**です。

---

## 3. 画面構成と役割

### 3-1. Chat（音声会話メイン画面）
用途:
- ユーザーがふれまーるちゃんと話す入口
- 音声会話 / テキスト入力 / クイック導線を集約

主な表示要素:
- 上部ヒーロー: ふれまーるちゃんの全身表示
- 「ただいま聞いてるよ」: 音声受付状態
- 右側のナマケモノ: ふれまーるちゃんと一緒にいる相棒表現
- チャット履歴: 感情差分アバターを出し分ける対象
- クイックカード: 回復費 / 今日の気分 / ライフログ

実装時の想定:
- Web Audio / 音声認識 / 音声合成
- 会話履歴 API 連携
- 感情分析結果に応じたアバター差し替え

### 3-2. ダッシュボード
用途:
- 今月のごほうび予算や回復支出の可視化
- 「いまどれくらい整っているか」を見せる画面

主な表示要素:
- 予算 / 使用額 / 残額
- 回復支出の推移
- ストレス・回復バランス
- 最近のアクティビティ
- 補助キャラクターとしてナマケモノ画像を配置

実装時の想定:
- DynamoDB 等の保存データ表示
- 集計 API 連携
- 週次 / 月次データ反映

### 3-3. ダイアリー
用途:
- 会話から生まれた日次サマリ
- ライフログの結果表示

主な表示要素:
- 日付
- 今日の気分
- ふれまーる度
- 会話から生まれたライフログ
- 歩数 / 睡眠 / ハイライト

実装時の想定:
- 日次集計ジョブ結果表示
- 会話要約 / 感情要約 / ライフログ生成

### 3-4. 回復提案
用途:
- 疲れているタイミングで、やさしい回復案を提示

主な表示要素:
- 今日のおすすめ回復
- 0円回復
- 小さなごほうび
- おすすめ動画
- おすすめ記事
- 回復ルート

実装時の想定:
- 回復提案ロジック
- レコメンド API
- 動画 / 記事 / 商品リンク表示

### 3-5. 設定
用途:
- 設定系情報の操作
- プロフィール確認
- 将来機能の案内

主な表示要素:
- 通知設定
- ダイアリー時間
- ごほうび予算
- テーマ
- プライバシー / アカウント
- アバターカスタマイズ
- 開発中機能
- ナマケモノ画像による世界観補助

実装時の想定:
- ユーザー設定 API
- テーマ切替
- 認証・会員情報連携

## 5. GitHub Copilot に伝えたい実装ルール

### 5-1. チャットアバターの感情差し替え
チャットの assistant メッセージでは、応答内容や感情分析に応じて  
`assets/emotions/` 配下の画像を切り替えて使用してください。

推奨ルール例:
- 共感系の返答 → `support.png`
- 明るい励まし → `happy.png`
- 説明や補足 → `shy.png`
- 成功 / ごほうび / 達成 → `excited.png`
- 通常応答 → `neutral.png`
- 音声待機中 → `listening.png`

### 5-2. 既存 HTML の反映ポイント
- `index.html` 内の assistant メッセージ画像には `data-emotion` 属性を付与済みです
- `app.js` 内に `getEmotionAvatarPath(emotion)` を用意しています
- Copilot には、この関数をベースに API の応答に応じてアバターを差し替えるよう実装させてください

### 5-3. ナマケモノの扱い
- ナマケモノは、ふれまーるちゃんの相棒・雰囲気づくりとして使います
- 絵文字ではなく、`assets/sloth-buddy.png` の画像を使う構成に変更済みです
- Chat 画面の「ただいま聞いてるよ」エリアでは、ふれまーるちゃん + ナマケモノで待機状態を見せています

## 6. このモックを本実装するときの注意

- この HTML は**静的モック**です
- 実際のシステムでは API 接続、認証、音声処理、会話保存、分析結果取得を追加してください
- 見た目はこのデザインとアセット配置をなるべく維持してください
- ダッシュボードの図版は**画像を貼るのではなく HTML コンポーネントで実装**してください
- チャット画面では、**感情差分画像を UI の一部として積極的に使う**前提です
- PC で表示してもスマホサイズのモックとして見える構成です
