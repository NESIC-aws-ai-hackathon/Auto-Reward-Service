# オートリワードサービス（ARS） — 機能仕様書

## 概要

本書はリワードちゃん（LINE Bot ＋ LIFF ダッシュボード）の全機能をユーザーストーリー別に整理し、
対応するバックエンド API・エンドポイント・処理フローを記載する。

---

## システム構成

| レイヤー | 技術 | エンドポイント |
|---------|------|--------------|
| LINE Bot（Webhook） | Lambda + API Gateway | `POST /webhook` |
| LIFF ダッシュボード | Lambda + API Gateway | `GET /liff`, `GET /liff/onboarding` |
| LIFF API | Lambda + API Gateway | `/api/{path}` |
| バッチ処理 | Lambda + EventBridge | スケジュール実行 |

**ベース URL**: `https://6seky2k0ge.execute-api.ap-northeast-1.amazonaws.com`

### 🔔 US-7: Push 通知を受け取る

| タイミング | トリガー | 内容 | API/処理 |
|----------|---------|------|---------|

## 6. 認証方式

| 対象 | 方式 | 検証項目 |
|------|------|---------|

## 7. Intent 分類（Bedrock Nova Micro）

| Intent | 説明 | 例 |
|--------|------|-----|
| `EXPENSE` | 支出報告 | 「プリン買った 320円」「ランチ 1200円」 |
| `REWARD` | ご褒美要求 | 「疲れた」「頑張ったから何かほしい」 |
| `GREET` | 挨拶 | 「こんにちは」「おはよう」 |
| `CHAT` | 雑談 | 上記に該当しない会話 |
| `ONBOARDING` | 情報提供 | 「月収 30万」（オンボーディング中） |
| `PROFILE_UPDATE` | プロフィール変更 | 「Netflix 解約した」「昇給して32万になった」「誕生日8月3日」 |
| `CONFIRM_YES` | 肯定 | 「はい」「うん」「OK」 |
| `CONFIRM_NO` | 否定 | 「いいえ」「違う」「やめる」 |
| `UNKNOWN` | 不明 | 判定不能 |

## 10. レシート解析の非同期処理（SQS）

| ステップ | 処理 | タイムアウト |
|---------|------|-----------|
| 1 | 画像受信 → SQS にジョブ投入 | 即時（29秒以内） |
| 2 | 「解析中...」Reply で返答 | - |
| 3 | `ReceiptProcessorFunction` が SQS から取得 | 最大 60秒 |
| 4 | Nova Lite で解析 → 支出保存 → Push 通知 | - |

**SQS リソース**: `${StackName}-receipt-queue`（可視性タイムアウト: 60秒、メッセージ保持: 1時間）

## 11. 繰り越し機能（F2-07）

| 項目 | 内容 |
|-----|------|

## 14. リッチメニュー自動登録

```bash
# スクリプト実行方法
export LINE_CHANNEL_ACCESS_TOKEN=<your_token>
python scripts/register_rich_menu.py --image images/rich_menu.png --clean
```

オプション:
- `--image`: リッチメニュー画像ファイルパス
- `--list`: 登録済み一覧を表示
- `--clean`: 既存メニューを全削除してから登録
